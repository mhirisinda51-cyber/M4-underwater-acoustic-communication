\# Model Assumptions and Limitations



\## Current SNR model



The first SNR calculation uses illustrative values:

\- Source level: 190 dB

\- Noise level: 60 dB

\- SNR estimate: source level - transmission loss - noise level



These values are assumptions for an initial test, not measured underwater data.



\## Limitation



The current model uses a fixed noise level. A more realistic acoustic link budget

must define the source-level and noise-level reference units consistently and

account for the receiver bandwidth. Noise also varies with frequency and

environment.



Therefore, the current SNR and capacity results are illustrative estimates.

They should not be treated as validated predictions of a commercial modem's

performance.



\## Next improvement



Use published modem specifications and clearly stated channel/noise assumptions

to refine the model before making a numerical comparison.
